### 🌟 Featured Projects

#### 🥛 [DairyAI Nexus – Cloud-Based SaaS Dairy ERP & Telemetry Platform](https://dairy-ainexusfrontend.vercel.app)
> *High-throughput multi-tenant SaaS ERP with automated M2M hardware telemetry ingestion and real-time ledger accounting.*
> [[Backend Source Code](https://github.com/kashilingbhusnar21/SmartDairy-Multi-tenant-System-)] • [[Frontend Source Code](https://github.com/kashilingbhusnar21/DairyAinexusfrontend)] • [[Live Demo](https://dairy-ainexusfrontend.vercel.app)]

- **Tenant Isolation & Security**: Designed multi-tenant architecture with JWT-based RBAC and row-level data isolation, fronted by NGINX reverse proxy on AWS EC2.
- **M2M Hardware Telemetry**: Created an autonomous ingestion pipeline with pre-shared Device API keys to stream raw milk analyzer and scale metrics, eliminating data fraud.
- **Real-Time Financial Ledger**: Built ACID-compliant ledger with dynamic FAT/SNF rate engines, Redis caching, and automated debt deduction for cattle feed.
- **Cloud Scale & Load Tested**: Benchmarked with **Apache JMeter** handling **5,000 concurrent collectors (16,000+ requests)** with **sub-50ms latency** and **0.00% error rate**.
- **Automated Quality**: Backed by **83 unit & slice tests** via JUnit 5 & Mockito (>85% code coverage) in CI/CD.
- *Tech*: `Java` `Spring Boot` `MySQL` `Redis` `AWS (EC2, ELB, Auto Scaling)` `Docker` `NGINX` `Groq AI` `JUnit 5`

#### ⚡ [CodeArena – Microservices-Based Code Execution & DSA Platform](https://github.com/kashilingbhusnar21/CODEARENA-MICROSERVICES)
> *Asynchronous LeetCode-style code evaluation platform with sandboxed Docker runtime execution.*
> [[Microservices Backend](https://github.com/kashilingbhusnar21/CODEARENA-MICROSERVICES)] • [[Frontend](https://github.com/kashilingbhusnar21/CodearenaFrontend)]

- **Asynchronous Execution Pipeline**: Decoupled submission API and worker nodes via **RabbitMQ** with **Server-Sent Events (SSE)** for zero-polling real-time verdict streaming.
- **Design Pattern**: Implemented the **Strategy Pattern** for dynamic, extensible runtime execution across Java, Python, and C++.
- **Secure Docker Sandbox**: Hardened container isolation with `--network none`, strict resource quotas (1 CPU, 256MB RAM), and fork-bomb prevention (`--pids-limit=50`).
- **Warm Container Pooling**: Engineered a pre-initialized container pool reducing execution startup latency from 3–5 seconds down to sub-second speeds.
- **Test Engine**: Automated evaluation suite supporting 100+ DSA problems validated against 400+ public and hidden test cases.
- *Tech*: `Java` `Spring Boot` `Microservices` `React` `RabbitMQ` `Docker` `MySQL` `AWS S3` `Spring Security` `SSE`
